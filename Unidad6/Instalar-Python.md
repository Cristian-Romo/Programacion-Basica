- Ve al sitio oficial de Python en tu navegador: https://www.python.org

- En la pagina principal, haz clic en el boton "Download Python", ese boton instalara la version mas reciente de python

- Se descargara un archivo ejecutable (.exe)

- Abre el archivo .exe que descargaste.

- En la ventana del instalador, marca la casilla "Add Python to PATH" (es importante para que se pueda ejecutar en la terminal).

- Luego, haz click en instalar ahora.

- Espera a que se complete la instalacion y, cuando termine, veras un mensaje de que la instalacion termino correctamente.

Pasos extras:

- Abre el cmd (para aseguarar que quedo instalado correctamente).

- Escribe el siguiente comando y presiona Enter:

- python --version

- Si todo esta bien se mostrara tu version de python
